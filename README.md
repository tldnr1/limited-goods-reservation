# Limited Goods

Limited Goods is restarting as a contract-first service for the core purchase flow of limited streamer merchandise.

The project is currently in its initialization phase. It has no application implementation yet, and its business states, API contract, runtime architecture, and performance targets are intentionally undecided.

## Direction

- Define how a buyer secures limited inventory and completes payment.
- Validate inventory and payment consistency, performance, and security within limited cloud cost and compute resources.
- Choose architecture and technology from observed constraints and bottlenecks.
- Start from a Python service direction without porting the previous Java/Spring implementation.
