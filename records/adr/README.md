# ADR

This directory stores accepted architecture decision records.

ADR files are committed to `dev` and `main` when a decision affects the project direction.

Use ADRs for decisions that are hard to reverse or important to explain in a portfolio review.

Current decisions:

```text
0001-v2-layered-stock-strategy.md
0002-v3-2-minimal-redis-front-gate.md
```

Template:

```text
# ADR 0000. Decision Title

## Status

Accepted

## Context

What problem or trade-off forced this decision?

## Decision

What did we choose?

## Alternatives

What other options were considered?

## Consequences

What gets better, worse, or intentionally deferred?

## Evidence

Link related experiment results when available.
```
