# Experiments

This directory stores measured experiment results.

Experiment records are committed to `dev` and `main` when they support an architectural decision or version result.

Use experiments for benchmark results, failure reproduction, load-test summaries, and comparison tables.

Suggested file name:

```text
v1-oversell-baseline.md
v2-stock-strategy-comparison.md
v3-1-entry-control.md
v3-1-entry-control-initial.md
v3-2-payment-delay-isolation.md
v4-reward-policy-comparison.md
```

Template:

```text
# Experiment Title

## Version

## Question

## Setup

## Scenario

## Metrics

## Result Summary

## Decision Impact

## Limitations

## Follow-up
```
